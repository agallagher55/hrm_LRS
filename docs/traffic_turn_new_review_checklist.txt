TRNLRS_traffic_turn_new -- Review Checklist
============================================

Purpose
-------
scripts/05_rebuild_traffic_turns.py produced a staging feature class,
SDEADM.TRNLRS_traffic_turn_new, by spatially remapping turn edge references
from the old edge source (TRN_street) to the new one (TRNLRS_TRN_STREET).
AUTO_SWAP_AND_REBUILD was False, so nothing in production has changed yet --
the current TRNLRS_traffic_turn and TRNLRS_street_network are untouched.

This review exists because the remap is a best-effort spatial match, not a
guaranteed 1:1 translation. Two things can go wrong silently:
  1. A turn gets mapped to the WRONG edge at a multi-leg intersection
     (the angle-based tiebreaker in find_new_oid() is a heuristic).
  2. A turn gets dropped (skipped) that shouldn't have been, or one that
     should have been dropped (e.g. references a removed segment) wasn't.

Once you swap TRNLRS_traffic_turn_new into place, the old FC is deleted and
the network dataset is rebuilt -- there is no cheap "undo" (see
docs/network_traffic_turns.md, controller-dataset locking). Review now,
before that point.
